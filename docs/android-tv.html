电视盒子 / Android TV 安装 TVS APK

按 CPU 架构选对 APK，再用 U 盘或 ADB 侧载进盒子。下面把 ABI 选择、几种传包方式和未知来源权限一次说清。

先选对 ABI：三个 APK 该下哪个

TVS 的 Android 包按 CPU 架构分包，下错了装不上或装上闪退。

ABI适用设备体积
arm64-v8a绝大多数情况选这个：近几年的电视盒子、Android TV、智能电视、手机约 32 MB
armeabi-v7a老旧的 32 位盒子与老电视（2016 年前后的低端机型）约 31 MB
x86_64安卓模拟器、少数 x86 架构的盒子 / 电视棒约 34 MB

不确定设备是什么架构，可以装个「CPU-Z」或「设备信息」类应用查看，或者直接先试 arm64-v8a——绝大多数设备都能装上。 上游 nodejs-mobile 没有 32 位 x86 产物，因此不提供 x86 包。

到 Releases 下载最新 APK

系统要求与占用

  • 最低 Android 7.0（API 24），targetSdk 36。
  • APK 为 Release 构建，使用调试密钥签名，仅供侧载安装，不会上架应用商店。
  • native 库采用压缩打包（useLegacyPackaging），安装时由系统解压，因此设备上会额外占用约 80 MB。存储紧张的老盒子请先留够空间。

电视盒子没有浏览器，怎么把 APK 弄进去

方法一：U 盘（最通用）

  1. 在电脑上把 APK 拷到 U 盘。
  2. U 盘插进盒子，用盒子自带的文件管理器（或「ES 文件浏览器」「当贝文件管理」等）打开 U 盘。
  3. 点击 APK，按提示允许「未知来源」安装。

方法二：ADB 局域网安装（最快，适合有电脑）

  1. 盒子上打开「开发者选项 → USB 调试 / 网络调试」（通常在「设置 → 关于」里连点版本号 7 次解锁开发者选项）。
  2. 记下盒子的局域网 IP（设置 → 网络里能看到）。
  3. 电脑上执行：
    adb connect 盒子IP:5555
    adb install tvs-1.x.x-arm64-v8a.apk
  4. 盒子屏幕上可能弹出授权确认，选允许。

方法三：局域网 / 网盘传输

用「ES 文件浏览器」「小白文件管理器」之类支持局域网共享或网盘的应用，把电脑上的 APK 直接拉到盒子里安装。 部分盒子自带的应用商店也有内置浏览器，可以直接输入 Releases 页面的下载直链。

允许未知来源

侧载安装都需要放开这项权限：

  • Android 7 ~ 7.1：设置 → 安全 → 未知来源，打开开关。
  • Android 8 及以上：权限是按应用授予的。系统会在你点击 APK 时提示，跳转到对应设置页给发起安装的那个应用（文件管理器 / 浏览器）打开「安装未知应用」。

遥控器怎么操作

TVS 做了 D-pad 遥控器按键导航与焦点管理，针对 Android TV 与电视盒子的场景优化，方向键 + 确认键即可完成浏览、搜索与播放控制，不需要外接鼠标。 播放器内支持倍速、亮度 / 音量调节、片头片尾跳过与断点续播。

应用内更新

从 1.1.2 起，Android 端发现新版本后可以在弹窗里点「立即更新」，应用会自动下载对应架构的 APK、校验 SHA-256 后调起系统安装器，不用再跳回 GitHub 手动下载。

注意：1.0.9 及更早版本的更新检查读的是已经移除的旧 releases/ 目录，不会再弹出更新提示，请手动到 Releases 页面 下载新版。

装好之后

TVS 是空壳应用，首次启动没有任何内容。接下来需要：

  • 导入羊壳（PeekPili）格式的订阅配置 —— 点播内容来源
  • 导入 M3U / TXT / JSON 直播源 —— 直播频道来源
