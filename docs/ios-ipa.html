iOS / iPadOS 安装 TVS：自签名 IPA 侧载教程

TVS 的 iOS 版是自签名 IPA，需要你自己签名后侧载。下面是四种可行方式，以及签名过期、安装失败的处理办法。

先说清楚：这是自签名（self-signed）IPA，不是 App Store 版本。 TVS 没有上架 App Store，也没有企业签名，安装包用的是 ad-hoc 自签名证书， iOS 不会直接接受它——你必须用自己的 Apple ID 或其他签名工具重新签名之后才能侧载。

下载 IPA

到 Releases 最新版 下载 tvs-selfsign-版本号.ipa（约 34 MB）。 每个版本的 SHA-256 校验值都列在 版本记录 里，下载后建议核对一遍。

四种侧载方式

1. 爱思助手（Windows / macOS，最省事）

  1. 数据线连接 iPhone / iPad，打开爱思助手并信任本机。
  2. 进入「工具箱 → IPA 签名安装」，选择下载好的 IPA。
  3. 用自己的 Apple ID 登录进行签名（普通 Apple ID 即可，不需要开发者账号）。
  4. 签名完成后点安装，等待设备端出现图标。

普通 Apple ID 签出来的证书有效期 7 天，到期后应用会闪退，需要重新签名安装；付费开发者账号签名有效期 1 年。

2. AltStore / SideStore（无需电脑常驻）

  1. 在电脑上装 AltServer，给设备安装 AltStore。
  2. 把 IPA 传到手机（AirDrop、文件 App、iCloud 均可）。
  3. 在 AltStore 里点「+」选择该 IPA，用 Apple ID 完成签名安装。
  4. AltStore 会在同一 Wi-Fi 下自动续签，避免 7 天过期。

3. 巨魔商店 TrollStore（永久签名，限特定系统版本）

如果你的设备系统版本在 TrollStore 支持范围内（不同分支覆盖的 iOS 版本不同，请以 TrollStore 官方说明为准）， 可以直接用 TrollStore 安装 IPA，安装后永久有效，不会 7 天过期，也不需要电脑。 把 IPA 用「共享 → TrollStore」打开即可。这是长期使用体验最好的方式。

4. 各类在线自签 API / 签名服务

把 IPA 和签名证书交给第三方服务生成安装链接。这类服务需要你上传证书或 Apple ID，存在账号与隐私风险，请自行评估， 本项目不推荐也不背书任何具体服务。

安装后的信任步骤

用 Apple ID 自签的应用，首次打开会提示「未受信任的开发者」。到 设置 → 通用 → VPN 与设备管理，找到你的 Apple ID 对应的描述文件，点「信任」，再回到桌面打开 TVS。

常见问题排查

现象原因与处理
安装到一半失败 / 图标一直转圈多为签名失败或设备已装同 Bundle ID 的旧版。删掉旧版后重新签名安装。
打开就闪退签名过期（免费 Apple ID 7 天）。重新签名安装即可，数据保留在设备本地。
提示「未受信任的开发者」按上面的信任步骤在「VPN 与设备管理」里信任描述文件。
「无法验证 App」且没有网络免费证书首次启动需要联网校验，连上网再打开。
装好了但没有任何内容正常。TVS 是空壳设计，需要先导入羊壳（PeekPili）订阅。

iPadOS 能装吗？

能。同一个 IPA 同时支持 iPhone 与 iPad，侧载方式完全一致。

装好之后

TVS 安装完是一个空壳，不含任何内容、站点或频道。接下来需要：

  • 导入羊壳（PeekPili）格式的订阅配置 —— 点播内容来源
  • 导入 M3U / TXT / JSON 直播源 —— 直播频道来源
