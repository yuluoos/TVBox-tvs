直播源导入：M3U / TXT / JSON 三种格式

直播频道和点播订阅是分开的两套。直播源用通用格式，TVS 会自动识别，下面是三种格式的写法和播放失败的排查表。

TVS 的直播和点播是两套独立的东西：点播内容来自羊壳（PeekPili）订阅配置， 直播频道则单独导入直播源。直播源用的是通用格式，不受羊壳格式限制。

支持的三种格式

TVS 会自动识别导入的直播源属于哪种格式，你不需要手动指定。

1. M3U / M3U8 播放列表

最常见的 IPTV 格式，每个频道由一行 #EXTINF 元信息加一行播放地址组成。 group-title 决定分组，tvg-logo 决定台标：

#EXTM3U
#EXTINF:-1 tvg-name="频道名" tvg-logo="https://.../logo.png" group-title="央视",频道名
http://example.com/stream.m3u8

2. TXT（#genre# 分组格式）

国内直播源常见的纯文本格式，用 #genre# 标记分组，其余每行是「频道名,播放地址」：

央视,#genre#
CCTV-1,http://example.com/cctv1.m3u8
CCTV-2,http://example.com/cctv2.m3u8
卫视,#genre#
湖南卫视,http://example.com/hunan.m3u8

3. JSON

结构化的 JSON 直播源同样支持，导入后一样会解析出分组与频道列表。

导入后能用到什么

  • 频道分组浏览：按源里的分组（央视 / 卫视 / 地方等）分类展示。
  • 台标显示：源里带了 logo 地址就会显示台标，图片走内置本地代理处理防盗链。
  • 独立直播播放器：直播有自己的播放页面，交互与点播播放器分开，遥控器 D-pad 可直接操作。

播放失败怎么排查

现象原因与处理
整个源导入后没有任何频道格式不在 M3U / TXT / JSON 三种之内，或文件内容为空 / 地址已失效。换个源试试。
频道列表有，但全部播不了多为网络问题：源需要特定网络环境、被限流，或组播地址在你的网络里不可达。
个别频道卡顿或转圈单个流的服务端问题，和播放器无关。同名频道换一条线路。
台标不显示源里没写 tvg-logo，或 logo 地址已失效。
分组全挤在一起源本身没写 group-title / #genre# 分组信息。

TVS 内置本地 HTTP 代理，负责图片防盗链代理、请求头转发和 m3u8 过滤； 资源代理会手动跟随重定向并在每一跳保留自定义请求头（User-Agent 等），这修复了部分防盗链站点播放失败的问题（1.1.2）。

播放器能力

直播和点播共用同一个播放内核：media_kit（libmpv），支持主流格式与 m3u8 流。 本地代理层还会对 m3u8 分片做广告过滤处理。

本项目不提供任何直播源。TVS 只负责解析和播放你自己导入的源， 不提供、不推荐、不分发任何频道地址或源列表。请勿在 Issues / Discussions 中索取或分享内容源。
