羊壳（PeekPili）订阅导入与空壳设计说明

TVS 装完是个空壳，内容全靠你自己导入的订阅。下面说明导入步骤、格式限制，以及导入后没内容该怎么查。

什么叫「空壳」

TVS 采用羊壳（PeekPili）一类的空壳设计：应用本体不内置任何内容、站点、频道或数据源。 装完打开是一个空的框架，首页没有分类、搜索没有结果、直播没有频道——这不是 bug，是设计如此。

应用只提供三件事：解析、聚合、播放。内容从哪来、有没有、能不能播，完全取决于你自己导入的源。 卸载掉配置，应用就回到空壳状态。本项目不提供、不推荐、不分发任何内容源。

导入订阅配置

  1. 打开 TVS，进入「订阅」页。
  2. 新增一条订阅，填入你自己的订阅配置地址或内容。
  3. 等待解析完成，把它设为当前生效的配置。
  4. 回到首页，此时应该能看到该配置下的站点、分类与推荐列表。

支持多订阅管理：可以同时保存多条订阅配置，随时切换当前生效的那一条，不用来回删改。

格式限制：TVS 只解析羊壳（PeekPili）格式的订阅。 TVBox 自身的接口 / 配置格式不保证可用，其他壳的专有格式同样不保证。 如果导入后一片空白或报解析错误，第一件要确认的事就是这个配置是不是羊壳格式。

爬虫源（spider）与内嵌本地服务

羊壳订阅里常见 nodejs 类型的 spider 站点。TVS 内嵌了一个本地服务来运行爬虫源， 完整支持 nodejs 类型的 spider 站点，不需要你额外装什么运行环境。

应用在前后台切换时会自动检测并恢复这个本地服务，保证长时间使用的稳定性。 慢速设备上偶尔会遇到本地服务冷启动失败导致站点加载异常，1.1.2 已针对这个问题做了修复。

导入之后能用到什么

  • 首页：按当前配置的站点展示分类与推荐列表。
  • 聚合搜索：跨站点并发搜索，结果统一展示，不用一个站一个站翻。
  • 详情页：剧集解析与展示，支持多线路 / 多集数结构。
  • 解析播放：支持 parse 接口解析播放地址，自动处理嗅探与防盗链请求头。
  • 播放器：基于 media_kit（libmpv 内核），支持 m3u8 流，带片头片尾跳过、m3u8 广告过滤、断点续播、倍速与手势调节。
  • 听剧模式：独立音频播放页与全局迷你播放条，支持后台播放，可以息屏听剧。

导入后还是没内容？按这个顺序排查

检查项说明
配置格式对不对必须是羊壳（PeekPili）格式。TVBox 原生格式、其他壳的专有格式都不保证能解析。
有没有设为当前生效多订阅场景下，导入 ≠ 启用。要在订阅页把这一条切换为当前配置。
订阅地址还活着吗订阅地址失效、被墙、被限流都会导致解析空白。换个网络环境再试。
单个站点报错某个站点挂了不影响其他站点。切换站点看是不是普遍问题。
爬虫源站点全部失败可能是本地服务没起来。完全退出应用重开；老版本请先升级到最新版。

确认是应用本身的 bug，欢迎到 Issues 反馈（请附系统版本、应用版本与复现步骤）。 注意：源本身的可用性问题不属于本项目范围，也请不要在 Issues 里索取或分享内容源。

直播源是分开的

订阅配置管的是点播内容。直播频道走另一套导入流程，支持 M3U / TXT / JSON 三种通用格式， 见 直播源导入说明。
