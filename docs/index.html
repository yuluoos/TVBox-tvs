功能

TVS 将站点浏览、聚合搜索、视频播放和音频收听集中在一个应用中，适配手机触控、平板分栏与电视遥控器操作。内容、可用线路及云盘功能取决于你导入的源。

订阅与源管理

通过链接或本地文件导入羊壳（PeekPro）订阅，多订阅管理与切换；支持 Node.js 类型 spider 站点与独立悦听音频源。

点播与聚合搜索

按站点展示分类与推荐，跨站点并发聚合搜索，多线路 / 多集数详情页，支持 parse 解析播放与防盗链请求头处理。

播放器

支持片头片尾跳过、断点续播、倍速、画面比例与亮度 / 音量手势调节；加载时显示下载速度，全屏轻点空白区域可收起控件。支持对适用的 m3u8 点播播放列表过滤疑似广告分片，效果取决于源。

直播

识别 M3U / TXT（#genre# 分组）/ JSON 直播源，支持脚本与 RTMP 来源、频道分组、台标、多线路切换和播放模式选择；刷新失败时保留已有频道。

TV 与遥控器适配

D-pad 遥控器导航、焦点选择与播放菜单操作，针对 Android TV 与电视盒子优化。

听剧与音乐

独立音频播放页与全局迷你播放条，支持后台与息屏播放、选集和播放模式切换；小说支持定时停止，音乐可展示匹配到的封面与歌词。

云盘与文件预览

浏览源提供的云盘目录、打开媒体文件，并预览图片、PDF 和文本文件。具体内容与可用能力由源决定。

常见问题

安装后为什么什么内容都没有？

这是空壳设计。首次启动没有任何内容，需要在「订阅」页导入羊壳（PeekPro）格式的订阅配置；站点、分类、搜索结果、直播频道全部来自你导入的源。详见 羊壳订阅导入说明。

iOS 怎么安装这个 IPA？

IPA 为自签名构建，需要自行签名后侧载。常见方式：爱思助手、AltStore、巨魔（TrollStore）、各类自签 API。完整步骤与报错排查见 iOS 侧载教程。

macOS 打开提示「已损坏」或被拦截？

应用为 ad-hoc 自签名，会被 Gatekeeper 拦截。在「访达」中右键点击应用 → 打开，或到「系统设置 → 隐私与安全性」中允许。三种解法详见 macOS 安装说明。

Intel Mac 能用吗？

不能。内置的 Node 运行时上游只有 darwin-arm64 产物，因此仅提供 Apple Silicon 版本。

电视盒子该下哪个 APK？

绝大多数电视盒子和 Android TV 设备选 arm64-v8a；老旧 32 位设备选 armeabi-v7a；模拟器或少数 x86 盒子选 x86_64。传包方式与权限设置见 电视盒子安装说明。

支持 TVBox 的接口 / 配置吗？

不支持。TVS 只解析羊壳（PeekPro）格式的订阅，TVBox 自身的接口格式不保证可用。直播源则支持通用的 M3U / TXT / JSON，格式写法见 直播源导入说明。

技术栈

基于 Flutter（Dart）开发，视频播放使用 yl_player，音频播放使用 just_audio 与 audio_service，源运行依托本地 Node.js 服务。媒体格式兼容性取决于设备、平台与源。

订阅配置与播放记录使用 Isar 数据库和安全存储保存在本地；播放、内容查询和使用统计等功能会发起网络请求。
