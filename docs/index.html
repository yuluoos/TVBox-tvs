功能

订阅与源管理

导入羊壳（PeekPili）订阅配置，多订阅管理与切换；内嵌本地服务运行爬虫源，完整支持 nodejs 类型 spider 站点。

点播与聚合搜索

按站点展示分类与推荐，跨站点并发聚合搜索，多线路 / 多集数详情页，支持 parse 解析播放与防盗链请求头处理。

播放器

基于 media_kit（libmpv 内核），支持 m3u8 流；片头片尾跳过、m3u8 广告过滤、断点续播、倍速与手势调节。

直播

自动识别 M3U / TXT（#genre# 分组）/ JSON 三种直播源格式，频道分组浏览、台标显示、独立直播播放器。

TV 与遥控器适配

D-pad 遥控器按键导航与焦点管理，针对 Android TV 与电视盒子的使用场景优化。

听剧模式

独立音频播放页与全局迷你播放条，支持后台播放（audio_service），可息屏听剧。

常见问题

安装后为什么什么内容都没有？

这是空壳设计。首次启动没有任何内容，需要在「订阅」页导入羊壳（PeekPili）格式的订阅配置；站点、分类、搜索结果、直播频道全部来自你导入的源。详见 羊壳订阅导入说明。

iOS 怎么安装这个 IPA？

IPA 为自签名构建，需要自行签名后侧载。常见方式：爱思助手、AltStore、巨魔（TrollStore）、各类自签 API。完整步骤与报错排查见 iOS 侧载教程。

macOS 打开提示「已损坏」或被拦截？

应用为 ad-hoc 自签名，会被 Gatekeeper 拦截。在「访达」中右键点击应用 → 打开，或到「系统设置 → 隐私与安全性」中允许。三种解法详见 macOS 安装说明。

Intel Mac 能用吗？

不能。内置的 Node 运行时上游只有 darwin-arm64 产物，因此仅提供 Apple Silicon 版本。

电视盒子该下哪个 APK？

绝大多数电视盒子和 Android TV 设备选 arm64-v8a；老旧 32 位设备选 armeabi-v7a；模拟器或少数 x86 盒子选 x86_64。传包方式与权限设置见 电视盒子安装说明。

支持 TVBox 的接口 / 配置吗？

不支持。TVS 只解析羊壳（PeekPili）格式的订阅，TVBox 自身的接口格式不保证可用。直播源则支持通用的 M3U / TXT / JSON，格式写法见 直播源导入说明。

技术栈

Flutter（Dart）跨平台，覆盖 iOS / iPadOS / Android / Android TV / macOS；播放内核为 libmpv（media_kit）； 数据用 Isar 数据库 + 安全存储全部本地保存，无云端账号体系，隐私数据不出设备。
