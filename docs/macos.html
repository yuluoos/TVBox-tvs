macOS 安装 TVS：DMG 下载与「已损坏」解决

应用是 ad-hoc 自签名，首次打开必被 Gatekeeper 拦截。下面三种放行方式任选其一，另外说明为什么 Intel Mac 用不了。

只有 Apple Silicon 版本。TVS 内嵌的 Node 运行时上游只提供 darwin-arm64 产物， Intel Mac 无法运行爬虫源，因此不发布 x86_64 版 DMG。M1 / M2 / M3 / M4 及之后的机型都可以用。

下载与安装

  1. 到 Releases 最新版 下载 tvs-版本号.dmg（约 41 MB）。
  2. 双击挂载 DMG。DMG 使用 LZMA（ULMO）压缩，需要 macOS 10.15+ 才能挂载。
  3. 把 TVS 拖进「应用程序」文件夹。
  4. 首次打开不要双击，见下一节。

下载后建议核对 SHA-256，校验值列在 版本记录 里。终端执行：
shasum -a 256 ~/Downloads/tvs-1.x.x.dmg

提示「已损坏，无法打开」或「无法验证开发者」怎么办

这不是文件损坏。TVS 是 ad-hoc 自签名、未经 Apple 公证（notarization）的应用， Gatekeeper 对从网上下载的这类应用一律拦截，报错文案就是「已损坏，请移到废纸篓」。三种解法，从简单到彻底：

方法一：右键打开（推荐先试这个）

在「访达」的应用程序文件夹里右键点击 TVS → 打开，在弹出的对话框里再点一次「打开」。 这一步告诉系统你明确信任这个应用，之后就能正常双击启动了。

方法二：隐私与安全性里放行

如果双击后被拦截，打开系统设置 → 隐私与安全性，往下滚到「安全性」区域， 会看到一行「已阻止使用"TVS"，因为来自身份不明的开发者」，点右边的「仍要打开」。

方法三：移除隔离属性（前两种都不行时）

macOS 会给下载的文件打上 com.apple.quarantine 标记。在终端执行：

xattr -dr com.apple.quarantine /Applications/TVS.app

需要输入密码。执行后再打开即可。较新的 macOS（Sequoia 及之后）收紧了 Gatekeeper， 方法一有时会失效，这条命令通常是最有效的。

常见问题排查

现象原因与处理
DMG 双击无法挂载系统版本低于 macOS 10.15。DMG 用 LZMA 压缩，旧系统不支持。
「TVS 已损坏，无法打开」Gatekeeper 拦截，不是文件坏了。按上面三种方法之一放行。
Intel Mac 打不开 / 提示架构不符不支持。仅提供 Apple Silicon（arm64）版本，原因见页首说明。
能打开但站点全部加载失败内嵌本地服务未起来。完全退出应用后重开；仍不行请到 Issues 反馈并附系统版本。
打开后一个内容都没有正常。TVS 是空壳设计，需要先导入羊壳（PeekPili）订阅。

Intel Mac 真的没办法吗

目前没有。限制来自上游依赖而不是打包配置：TVS 需要内嵌 Node 运行时来跑 nodejs 类型的 spider 爬虫源， 而该运行时上游只发布 darwin-arm64 产物。在 Intel Mac 上即使强行运行，爬虫源类站点也无法工作。

装好之后

TVS 是空壳应用，首次启动没有任何内容。接下来需要：

  • 导入羊壳（PeekPili）格式的订阅配置 —— 点播内容来源
  • 导入 M3U / TXT / JSON 直播源 —— 直播频道来源

数据用 Isar 数据库加安全存储全部保存在本地，没有云端账号体系，隐私数据不出设备。
